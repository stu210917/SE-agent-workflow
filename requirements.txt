# 本项目零第三方依赖，只使用 Python 标准库（3.9+）。
#
# 之所以不引入 LangGraph / Prefect / Airflow 之类的编排框架，与项目1 的理由一致：
# 作业考察的核心是「Workflow 编排、Agent 间通信、状态管理」这三件事本身，
# 用框架会把这些机制藏在抽象后面。本项目用约 1000 行实现了同等关键的机制：
# 节点与条件边、共享状态与版本化、消息总线、执行引擎与事件日志、并行与错误恢复。
#
# 项目1 的代码审查 Agent 以 vendored 方式内置在 codereview/ 目录，
# 因此本项目 clone 下来即可独立运行，不需要先安装项目1。
#
# 可选依赖（非必需，仅用于开发体验）：
#   pytest  —— 更友好的测试运行器（标准库 unittest 亦可）
#   ruff    —— 代码风格检查
#
# 安装可选依赖：pip install -r requirements-dev.txt
